## Entry

> The office plant has been here longer than three managers and outlived two restructures; it is the only one with job security.

## How it works

`main.ts` writes the one-line joke to `/output/entry.txt` (via `MAKEFUN_OUTPUT_DIR`, defaulting to `out`), after checking the gate: a single line of 1–200 characters.

Run it locally:

```sh
npx tsx main.ts
```
